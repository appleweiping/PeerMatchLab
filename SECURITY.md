# Security policy

PeerMatchLab processes local text and JSON files. Please report path traversal, unsafe deserialization, dependency compromise, unintended network access, or data disclosure concerns privately through GitHub's security advisory form.

Do not open a public issue containing real matching data, confidential documents, personal profiles, access tokens, or identifying conflict information. Sanitized correctness and denial-of-service reports may be filed publicly.

Only the latest release line receives security fixes during the pre-1.0 period.
